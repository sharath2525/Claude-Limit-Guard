# Privacy Policy for Claude Limit Guard

Effective date: May 10, 2026

Claude Limit Guard is an unofficial browser extension that displays Claude usage limit information inside the Claude website.

## Data the extension accesses

When you use the extension on `https://claude.ai`, it may access:

- Your Claude organization identifier from the Claude website cookie named `lastActiveOrg`.
- Claude usage limit information returned by Claude's own usage API, such as session usage, weekly usage, and reset times.

The extension does not access this information on any website other than `https://claude.ai`.

## How the data is used

The accessed data is used only to show usage limit bars and reset countdowns inside the Claude interface.

## Data collection and sharing

Claude Limit Guard does not collect, transmit, sell, rent, or share your personal data with the developer or any third party.

The extension does not use analytics, advertising, tracking pixels, or remote logging.

## Storage

Claude Limit Guard does not save user data to browser storage, extension storage, local storage, session storage, cookies, or an external server.

Usage information is kept only in memory while the Claude tab is open and disappears when the tab is closed or refreshed.

## Network requests

The extension only makes same-site requests from the Claude page to Claude-owned endpoints on `https://claude.ai`. It does not send data to developer-controlled servers or third-party services.

## Permissions

The extension requests no Chrome extension permissions and runs only on `https://claude.ai/*` pages.

## Changes to this policy

This policy may be updated if the extension's behavior changes. Any material change will be reflected in this file before the updated extension is submitted for review.
